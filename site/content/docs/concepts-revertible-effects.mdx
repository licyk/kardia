本页概述论文（[arXiv:2608.25512](https://arxiv.org/abs/2608.25512)）的 §3.1。定义与定理编号沿用论文。Cordis 如何实现效应，见 Cordis 参考中的[效应](/docs/reference-effects)；kardia 的 Rust 设计见使用指南中的[效应](/docs/guide-effects)和 [API 设计](/docs/development-design)。

时间可组合性（temporal composability）要求组件所做的每一处修改都**可追踪**且**可恢复**。论文把效应（effect）建模为函数 `Γ → Γ × (Γ → Γ)`：给定当前上下文，它返回修改后的上下文，*以及*一个显式的逆操作。把逆操作交给运行时，效应就可追踪；提供逆操作，效应就可撤销。

## 从非纯函数到上下文变换（§3.1.1）

任何非纯函数 `f : X ⇝ Y` 都可改写为上下文类型 `Γ` 上的纯函数 `f : Γ × X → Γ × Y`。固定输入 `x` 时，副作用就是自同态 `γ ↦ pr₁(f(γ, x)) : Γ → Γ`。因此效应位于**变换幺半群** `(Γ → Γ, ∘, id_Γ)` 中：

- 封闭性：效应的顺序组合仍是效应；
- 结合律：括号位置无关紧要；
- 单位元：`id_Γ` 是单位元。

`f` 的撤销是一个**左逆** `g`（`g ∘ f = id`，从不要求 `f ∘ g`）；论文直接称之为*逆操作*。

### 定义 1：扭转组合（twisted composition）

```text
(f₁, g₁) ∘ (f₂, g₂) := (f₁ ∘ f₂, g₂ ∘ g₁)
```

正向操作按通常顺序组合，逆操作按相反顺序组合。这使 `(Γ→Γ) × (Γ→Γ)` 成为一个幺半群 **`𝔗Γ`**（变换幺半群与其反幺半群的积），单位元为 `(id, id)`。

### 定义 2：效应上下文（effect context）

`∂Γ := Γ × (Γ → Γ)`，即一对 `(γ, φ)`：

- `γ`：当前状态；
- `φ`：**累加器**（accumulator），即迄今为止所有逆操作的复合；它能恢复初始状态。

初始效应上下文为 `(γ₀, id)`。反复应用得到塔 `Γ, ∂Γ, ∂²Γ, …`。

### 定义 3：track

```text
track_Γ(f, g) := (γ, φ) ↦ (f(γ), φ ∘ g)
```

- **定理 4**：追踪不改变正向行为：`pr₁ ∘ track(f,g) = f ∘ pr₁`。
- **定理 5**：`track` 是幺半群同态 `𝔗Γ → (∂Γ → ∂Γ)`：逐对追踪等于追踪它们的扭转组合。

### 定义 6：recover

```text
recover_Γ(γ, φ) := (φ(γ), id)
```

应用累加器，然后将其重置。

- **定理 7**：若 `g(f(γ)) = γ`，则 `recover(track(f,g)(γ,φ)) = recover(γ,φ)`。一个逆操作能撤销自身的被追踪步骤不会移动恢复目标。状态的**健全性不变量**（soundness invariant）是 `φ(γ) = γ₀`；从 `(γ₀, id)` 出发经此类步骤到达的每个状态都满足它，而 `recover` 会把状态带回 `(γ₀, id)`。
- 由定理 5，同样的结论对整个序列成立（式 11）。

## 效应函数（§3.1.2）

`track`/`recover` 有两个局限：

1. `track(f, g)` 在看到状态之前就固定了 `g`：一个统一的逆操作必须在每个状态下都有效。而实际的效应只需要一个*针对其被应用时状态*的逆操作（例如“删除我刚添加的那个条目，使用我刚分配的 id”）。
2. `recover` 要么全部撤销，要么什么都不做：无法只撤销一个效应而保留其他效应。

解决办法：在应用时返回逆操作（输入侧，`Γ → ∂Γ`），并让提升后的效应本身也返回一个逆操作（输出侧，`∂Γ → ∂²Γ`）。二者形状相同。

### 定义 8：效应函数与带见证的效应函数

- `𝔈Γ := Γ → Γ × (Γ → Γ)`，其中 `e(γ) = (δ, g)`：新上下文 `δ`，逆操作 `g`。
- `𝔈Γ*` 还带有一个**见证**（witness）`(δ, g) = e(γ) ⇒ g(δ) = γ`：逆操作在*效应被应用时的状态*下撤销该效应。满足 `g ∘ f = id` 的统一逆操作是其特例。

### 定义 9：效应组合 ⋄

```text
(f ⋄ g)(γ) := let (δ, s) = g(γ); (ε, t) = f(δ) in (ε, s ∘ t)
```

先运行 `g` 再运行 `f`，并组合逆操作，使 `f` 的逆操作先运行。

- **定理 10**：`(𝔈Γ, ⋄)` 是单位元为 `η(γ) = (γ, id)` 的幺半群；`(f,g) ↦ γ ↦ (f(γ), g)` 是同态 `𝔗Γ → 𝔈Γ`。
- **定理 11**：`𝔈Γ*` 是子幺半群（见证在组合下保持），且统一逆操作落在其中。

### 定义 12：effect（提升到效应上下文）

```text
effect_Γ : 𝔈Γ → ∂Γ → ∂²Γ
effect_Γ(e)(γ, φ) = let (δ, g) = e(γ) in ((δ, φ ∘ g), track_Γ(g, pr₁ ∘ e))
```

返回的逆操作本身是交换后那一对的 *track*：撤销是一个效应（按 `g` 变换），而撤销这次撤销就是再次执行该效应（`pr₁ ∘ e`）。

- **定理 13**：`effect(f) ⋄ effect(g) = effect(f ⋄ g)`。
- **定理 14**：投影可交换：提升后的正向映射与逆映射作用于状态的方式与 `f` 和 `g` 完全一致。
- **定理 15**：对带见证的 `e`：`g′(Δ) = (γ, φ ∘ g ∘ f)`。*状态*被精确恢复；*累加器*当且仅当 `g ∘ f = id` 时被恢复；无论如何 `(φ ∘ g ∘ f)(γ) = φ(γ)`，因此健全性不变量得以保持。所以 `effect` 一般**不会**把 `𝔈Γ*` 映到 `𝔈*∂Γ` 中，但撤销从不移动恢复目标。

## 效应迭代器（§3.1.3）

组件的加载不是一个效应，而是一个**序列**。

- **定理 16**：从 `(γ₀, id)` 出发应用 `e₁…eₙ ∈ 𝔈Γ*`，再按**相反顺序**撤销，每次撤销都恢复其对应应用所面对的状态，且每个中间状态都满足健全性不变量。LIFO 不需要更多条件。

### 定义 17：效应迭代器（effect iterator）

```text
ℑΓ  := μℑ. Γ → Γ × (Γ→Γ) × Maybe(ℑ)
ℑΓ* := the witnessed version (each iteration's inverse reverts at its state;
       the continuation is again witnessed)
```

（`ℑΓ*` 为带见证的版本：每次迭代的逆操作在其状态下撤销该次迭代，后续延续同样带见证。）

每次迭代产出 `(δ, g, o)`：新上下文、逆操作和延续（`Nothing` 表示结束，`Just(i)` 表示下一步）。

### 定义 18：效应迭代器变换

```text
effect^iter_Γ(i)(γ, φ) =
  let (δ, g, o) = i(γ); t = track_Γ(g, pr₁ ∘ i) in
  match o
  | Nothing  ⇒ ((δ, φ ∘ g), t)
  | Just(i′) ⇒ let (s, r) = effect^iter_Γ(i′)(δ, φ ∘ g) in (s, t ∘ r)
```

- 累加器变为 `φ ∘ g₁ ∘ … ∘ g_k`，按 LIFO 顺序撤销（定理 16）。
- `effect^iter` 与 `effect` 落在同一个 `∂Γ → ∂²Γ` 中，因此**迭代器就是效应**，凡是能用效应的地方都能组合迭代器（嵌套）。
- `Maybe(ℑ)` 延续在任意两次迭代之间提供了一个**边界**：在边界处，累加器恰好恢复迄今为止的各次迭代。这正是后文*中断*（L-Divert，见[演算](/docs/concepts-calculus)）与*取消*所用的挂钩。
- 迭代器是**具体化的定界延续**（reified delimited continuation）。主流语言通过 `yield` 暴露它，因此该模型“直接映射到这些语言已有的生成器上”。
- 普通效应函数可嵌入为一个首次迭代即产出 `Nothing` 的迭代器（式 19）。

<Callout type="info">
**在 kardia 中**：效应体接收一个 `EffectScope`。`scope.defer(..)` 收集一个逆操作但不设边界；`scope.yield_(disposer)` 收集一个逆操作并标记一个迭代边界；`scope.checkpoint()` 只标记边界。效应被释放后，二者都返回 `Err(Interrupted)`，因此 `?` 会在边界处结束效应体，只保留已收集的逆操作。见[效应](/docs/guide-effects)。
</Callout>

## 局部时间可组合性的含义

> 对组件所应用的任意效应函数序列，累加器都能恢复它开始时的上下文（定理 7），而撤销该序列时，每个逆操作拿到的都是其对应应用所面对的状态（定理 16）。加载组件就是运行一个迭代器并把它的逆操作累加到 `φ` 中；卸载组件就是应用 `φ`。

这里有意**未涵盖**两件事，留待后文的*独立性*（§3.4，见[上下文范式](/docs/concepts-context-paradigm)）解决：不按累加器所规定的顺序撤销，以及与其他组件的效应交错的序列。

## 工程要点

| 形式概念 | 实际含义 |
|---|---|
| 效应函数返回逆操作 | 每个注册 API 都返回一个撤销函数（disposer），它在*注册时*创建（因而可以捕获刚分配的 id）。 |
| 见证 | 对作者的义务：撤销函数必须恰好撤销那一次注册。运行时不做检查。 |
| `⋄` / 扭转组合 | 复合效应的撤销函数按创建顺序的逆序运行。 |
| `effect` 在下一层返回逆操作 | `ctx.effect(...)` 本身返回一个撤销函数，该撤销函数注册在*外层*作用域的累加器中：效应可以嵌套。 |
| 迭代器边界 | 多步初始化可以在步骤*之间*取消，只保留已完成步骤的逆操作。 |
| 健全性不变量 | 禁止释放两次：在任何应用都未产生过的状态下应用逆操作，撤销不了任何有意义的东西（实现强制“至多一次”）。 |

<Callout type="info">
**在 kardia 中**：`ctx.effect(label, |scope| async { .. })` 与 `ctx.effect_sync(..)` 返回一个 `EffectHandle`，注册在当前纤程（fiber）的累加器中；`scope.adopt(handle)` 把一个嵌套效应移到外层效应之下。`Disposer` 包装一个 `FnOnce`，因此“至多一次”由类型系统保证。见[效应](/docs/guide-effects)与 [API 设计](/docs/development-design)。
</Callout>
