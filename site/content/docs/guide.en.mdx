The guide explains how to build apps with kardia, from the config file of the `kardia` binary to plugins written in Rust and guest plugins that reload in place. It assumes kardia is [installed](/docs/installation); [Quick start](/docs/quick-start) shows a running app first.

## Which page do I need? [#which-page-do-i-need]

- **Running an app from a config file:** [The configuration file](/docs/guide-configuration), then [Hot reload](/docs/guide-hot-reload).
- **Writing plugins compiled into your app:** [Writing plugins](/docs/guide-plugins), [Services](/docs/guide-services) and [Effects](/docs/guide-effects).
- **Building your own host around the loader:** [Loader](/docs/guide-loader).
- **Writing plugins that reload without restarting the app:** [Guest plugins](/docs/guide-guests).

The guide describes how to use kardia. Why it is designed this way is on [Development](/docs/development), and the theory behind it on [Concepts](/docs/concepts).
