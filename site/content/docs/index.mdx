kardia 是 [Cordis](https://github.com/cordiverse/cordis) 的 Rust 实现。Cordis 是一个建立在时空可组合性（*spatiotemporal composability*）之上的插件框架（[论文](https://arxiv.org/abs/2608.25512)）。

一个应用是一棵由**插件**（plugin）组成的树。每个插件运行在一个**纤程**（fiber）中：

- **效应**（effect）：插件建立的一切（监听器、定时器、服务、子插件）都会被追踪，并在插件停止时撤销。
- **服务**（service）：插件提供服务，并声明自己依赖的服务。插件在依赖可用后启动，在某个依赖被替换时重启，在某个依赖消失时停止。
- **实时变更**：应用运行期间，可以重新配置、替换或热重载任意插件，应用的其余部分会随之调整。

## kardia、Cordis 与论文 [#kardia-cordis-and-the-paper]

**Cordis** 是论文 *A Programming Paradigm for Spatiotemporal Composability*（Shi、Zhang 与 Cui，[arXiv:2608.25512](https://arxiv.org/abs/2608.25512)）所描述的时空可组合性元框架，其参考实现用 TypeScript 编写。

**kardia** 用 Rust 重新构建了它。它以 `kardia` 和九个 `kardia-*` crate 的形式发布在 [crates.io](https://crates.io/crates/kardia) 上，API 文档见 [docs.rs](https://docs.rs/kardia)，源代码在 [GitHub](https://github.com/licyk/kardia) 上。
