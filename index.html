Cordis 的 Rust 实现

能干净撤销的插件，随时组合，随时替换

kardia 是一个插件框架：插件做过的每件事都能被完整撤销，服务在依赖变化时自动响应，配置文件的修改即刻作用于运行中的应用，访客插件可以原地热重载。它用 Rust 实现了论文《A Programming Paradigm for Spatiotemporal Composability》和 TypeScript 框架 Cordis。

WORKFLOW

从安装到热重载

四步搭起一个可以在运行中修改的应用。

  1. 01

    安装

    用 cargo add kardia 加入依赖，或用 cargo install kardia 安装命令行工具。

  2. 02

    编写插件

    用 #[plugin] 声明依赖的服务；在插件里注册的一切都会在它停止时自动撤销。

  3. 03

    描述应用

    在 kardia.yml 里列出插件、分组、隔离与配置，内置插件和访客插件都可以直接引用。

  4. 04

    运行中修改

    编辑配置或访客插件，kardia 只重启受影响的插件，其余继续运行。

WHY KARDIA

忠实移植，经过验证

kardia 按 Cordis 的代码与论文的定理实现，并用测试逐条核对。

  • 移植 Cordis 的全部测试

    TypeScript 实现的每个测试用例都已移植，或注明了不适用于 Rust 的原因。

  • 用性质测试检验定理

    随机生成插件编排与调度，检查论文的保持性、恢复精确性、顺序与汇合定理。

  • 编译期检查依赖

    #[plugin] 从签名读出依赖，访问未声明的服务无法通过编译。

  • 单锁并发模型

    每个根上下文只有一把锁，用户代码从不在锁内运行，状态转换可以安全地并发进行。

  • 三种访客后端

    WASM 沙箱、开发用的动态库、独立的子进程，共用同一套访客接口。
